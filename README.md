# Mantis Data Solutions Website

Personal website for David Hunt-Mateo / Mantis Data Solutions.

## Tech Stack

- Single HTML file with embedded CSS
- No build step, no dependencies, no framework
- Hosted on Cloudflare Pages

## Development

Just open `index.html` in a browser. No build required.

## Deployment

Connected to Cloudflare Pages for automatic deployment on push to `main`.
